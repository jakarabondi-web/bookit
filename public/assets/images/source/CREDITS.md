# Source photography

Masters for `scripts/prepare-assets.mjs`. Each file is framed 16:9 at full
resolution; the script derives the WebP and JPEG the app serves. Replacing a
photograph means dropping a new full-resolution 16:9 file here under the same
name and re-running `npm run assets`.

All eight are from [Pexels](https://www.pexels.com) under the
[Pexels licence](https://www.pexels.com/license/) — free to use commercially,
no attribution required. Credited here anyway, and kept as a record of where
each frame came from in case one needs to be re-cropped.
